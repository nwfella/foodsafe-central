# FoodSafe Central — Phase 1 MVP Implementation Plan

> **For Hermes:** Build directly (project small, full context from spike 001). No subagents needed.

**Goal:** Ship a US-first food-recall dashboard on GitHub Pages: last 12 months of FDA enforcement data, search-as-you-type, zero-dependency single-file HTML, refreshed 2×/day by a GitHub Actions cron.

**Architecture:** GH Actions cron runs `build_data.py` → regenerates `data/recalls.json` → commits on change → GH Pages serves `index.html` + JSON statically. All client-side, no backend, $0/month.

**Tech Stack:** Python 3 (stdlib only), GitHub Actions, single-file HTML/CSS/JS (no frameworks).

**Repo:** `nwfella/foodsafe-central`, Pages from `main` root. Project already contains `spikes/001-source-parse-quality/` (proven parsers — reuse them).

---

### Task 1: Production fetcher `build_data.py`

**Objective:** Fetch ~12 months of FDA food enforcement from openFDA, normalize into the validated schema, paginate past the 1000-record cap, write `data/recalls.json` with a `meta` block.

**Files:**
- Create: `build_data.py` (repo root)
- Output: `data/recalls.json`

**Key implementation points (from spike 001, all verified):**
- URL built manually — `urllib.parse.quote()` double-encodes `+TO+` → HTTP 500.
  `https://api.fda.gov/food/enforcement.json?search=report_date:[YYYYMMDD+TO+YYYYMMDD]&limit=1000&skip=N`
- Paginate: loop `skip += 1000` until a page returns < 1000 results; `time.sleep(0.4)` between pages; retry once on 429/500 with 5s backoff.
- UPC scan BOTH `code_info` AND `product_description` (55% coverage proven).
- Dates: `YYYYMMDD` → ISO `YYYY-MM-DD` in `published_at`/`last_updated`.
- Status: Ongoing→ACTIVE, Terminated/Completed→TERMINATED.
- Keep `raw_code_info`, `raw_distribution`, `raw_reason` (transparency requirement).
- JSON shape: `{"meta": {generated_at, window_days, total, by_severity, by_status, by_hazard, with_upc}, "recalls": [...]}`.

**Verify:**
```bash
python build_data.py --out data/recalls.json
python -c "import json; d=json.load(open('data/recalls.json')); print(d['meta']); print(len(d['recalls']))"
```
Expected: total ≥ 200, meta counts present, dates are ISO.

### Task 2: GitHub Actions workflow

**Objective:** Refresh data 2×/day (06:00/18:00 UTC), commit only when changed, no infinite loop.

**Files:**
- Create: `.github/workflows/refresh.yml`

```yaml
name: refresh-recalls
on:
  schedule: [{cron: "0 6,18 * * *"}]
  workflow_dispatch: {}
permissions: {contents: write}
jobs:
  refresh:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with: {python-version: "3.12"}
      - run: python build_data.py --out data/recalls.json
      - run: |
          if ! git diff --quiet data/recalls.json; then
            git config user.name "github-actions[bot]"
            git config user.email "41898282+github-actions[bot]@users.noreply.github.com"
            git add data/recalls.json
            git commit -m "chore: refresh recall data [skip ci]"
            git push
          fi
```

**Note:** schedule workflow pushing to main cannot re-trigger itself (no `on: push`) → no loop. `[skip ci]` belt-and-braces.

### Task 3: Dashboard `index.html` (single file, zero-dep, dark)

**Objective:** Search-as-you-type over `data/recalls.json` with severity/status/state filters and a detail panel showing parsed + raw source data.

**Layout:** header (brand, ACTIVE count, last-updated, "US (FDA) — Canada (CFIA) soon" note) → controls row (search input, severity select, status select, state select incl. Nationwide) → result count → card list → detail overlay → disclaimer footer.

**Search/ranking (per keystroke, <1k records → linear is instant):**
1. UPC query (query is ≥8 digits): exact match on digit-stripped `upc_codes` → score 1000.
2. Haystack includes: precomputed lowercase concat of brand+product+description+reason+upc+lot+recall_number → +100.
3. Brand startsWith → +50.
4. Sort: score desc, then `published_at` desc. Cap render at 200 with "showing X of Y".

**Filters:** severity (Class I/II/III), status (default ACTIVE, "All" shows terminated), state (US states + Nationwide).

**Detail panel:** severity badge, hazard, status, dates, product rows (brand/product/UPC/lot/expiry), `consumer_action.instructions`, distribution raw text, blockquote with `raw_code_info`/`raw_distribution`/`raw_reason`, "View official record on FDA.gov" link.

**Trust/transparency:** footer disclaimer — "Not affiliated with any government agency. Data: FDA openFDA. A barcode check finding no recall does not mean a product is safe." Fetch failure banner (file:// or blocked) with "serve over HTTP" hint.

**Verify:** serve `python -m http.server`, curl 200, node smoke test of ranking against real JSON, visual check in preview pane.
